# orq.ai API Examples

Generated by Bartolo `orq` quickstart examples.

## Setup

```sh
orq -o json doctor
```

## Explore

```sh
orq activities --help
```

## Copy-Paste Commands

### Check setup

```sh
orq -o json doctor
```

### Inspect server defaults

```sh
orq server list
```

### Persist the default output format

```sh
orq default-format json
```

### Explore a command group

```sh
orq activities --help
```

### Run a grouped command

```sh
orq activities create entity-id --help
```

### Use the raw escape hatch

```sh
orq request get /v2/activity/{entity_id}
```
